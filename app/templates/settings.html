Event searches

The agent can search events (Ariel) with filters on source IP, destination IP, log source, log source type, username, event name, QRadar event ID and QID only. Every search returns at most 50 events and must include a filter. Longer time ranges scan more data.

Health metrics queries (disk, EPS, queues, CPU, memory) return up to 500 aggregated rows.
